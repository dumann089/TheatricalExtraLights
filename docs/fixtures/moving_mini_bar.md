# Moving Mini Bar

`theatricalextralights:moving_mini_bar` · family: [Moving heads & beams](/fixtures/moving-heads)

Seven individually tiltable beams on one bar.

## Personalities

| Mode | Channels |
|---|---|
| 5ch - Unite Beam | 5 |
| 35ch - Alone Beam | 35 |

Select the mode in the fixture config screen; the footprint changes immediately.

## 5ch - Unite Beam (5 ch)

All beams move and colour together.

| Ch | Function | Values |
|---|---|---|
| 1 | Intensity | 0 off to 255 full |
| 2 | Tilt | 0 to 255 |
| 3 | Red | 0 to 255 |
| 4 | Green | 0 to 255 |
| 5 | Blue | 0 to 255 |

### Channel by channel

**1 · Intensity** — Master dimmer. 0 is dark, 255 is full output. The beam, the projected spot and the dynamic light in the room all scale with it. Fades are smooth: the client interpolates between DMX frames.

**2 · Tilt** — Tilt of all seven beams together.

**3 · Red** — Red component of the additive colour mix.

**4 · Green** — Green component of the additive colour mix.

**5 · Blue** — Blue component of the additive colour mix. With red and green at 255 too the light is white; all three at 0 gives a dark fixture even with the dimmer up.
