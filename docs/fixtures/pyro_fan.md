# Pyro Fan — 10 Comets

`theatricalextralights:pyro_fan` · family: [Pyro & fireworks](/fixtures/pyro)

Ten tubes firing gold comets in a vertical fan.

- Found in the Theatrical: Pyro tab.

## Personalities

| Mode | Channels |
|---|---|
| 3-Channel Pyro Fan (All Tubes) | 3 |
| 10-Channel Pyro Fan (Per Tube) | 10 |

Select the mode in the fixture config screen; the footprint changes immediately.

## 3-Channel Pyro Fan (All Tubes) (3 ch)

| Ch | Function | Values |
|---|---|---|
| 1 | Fire | 0 idle, rising edge fires, 2 to 255 continuous |
| 2 | Tilt | 0 to 255 = 0° to 180° |
| 3 | Power | 0 to 255 = 0.7× to 2.6× |

### Channel by channel

**1 · Fire** — Fires all ten tubes; each rise from 0 fires one round, continuous values fire repeatedly.

**2 · Tilt** — Launch pitch. 0 is horizontal, about 128 is straight up (90°), 255 is horizontal the other way. Aim launchers before the show; the shells keep the angle for their whole flight.

**3 · Power** — Launch power, a multiplier on the shell speed. Low values keep the burst close to the stage, high values send it high and far.
