# Waltz Curtain Water Jets (Adjustable)

`theatricalextralights:waltz_curtain` · family: [Water jets](/fixtures/water-jets)

Curtain of swinging jets.

## 3-Channel Mode (labelled 2-Channel Mode) (3 ch)

The mode label in the screen still reads 2-Channel Mode; the footprint is three channels.

| Ch | Function | Values |
|---|---|---|
| 1 | Jet level | 0 off to 255 full |
| 2 | Tilt | 0 to 255 |
| 3 | Swing speed | 0 to 255 |

### Channel by channel

**1 · Jet level** — Turns the water on and sets its level. 0 is off; higher values raise the flow, which makes the jet taller and denser up to the height set in the fixture screen.

**2 · Tilt** — Base angle of the jets.

**3 · Swing speed** — Speed of the swinging motion, 0 still.
