# Fixture reference

Every block Extra Lights adds, grouped by family, with its DMX personalities and channel tables. All registry ids are prefixed `theatricalextralights:`. Values are 0 to 255 unless noted.

![Concert stage with Extra Lights](/images/overview-stage.png)

## Conventions

| Function | Decoding |
|---|---|
| Intensity / dimmer | 0 off to 255 full |
| Red, Green, Blue | Additive mix; 255/255/255 is white |
| Focus | Beam sharpness or cone width depending on the fixture; 0 tight, 255 wide or soft |
| Pan (moving heads) | 0 to 255 = −180° to 180° |
| Tilt (moving heads) | 0 to 255 = −225° to 45° |
| Strobe / shutter | 0 closed, 1 to 254 strobe slow to fast, 255 open |

Every fixture also has the **Fixture Wrench** mount editor (offset ±2.5 blocks, rotation ±180°) and can hang from a truss or stand on the floor.
